Qu'est-ce que Ludo ?

Le classique jeu de course en croix-et-cercle, repensé sur canvas HTML5 avec une esthétique synthwave de terminal. Faites un six pour libérer un pion, avancez dans le sens horaire, tombez sur un adversaire pour le renvoyer à la maison et reposez-vous sur les étoiles sûres. Un 6, une capture ou atteindre le centre accorde un nouveau lancer. Jouez de 2 à 4 joueurs contre les bots ou chacun son tour sur un même appareil. Sans installation, sans inscription, sans analytique — les dés et l'IA s'exécutent localement dans votre navigateur, et ça marche hors ligne.

trois façons de jouer

Tactile

  • Touchez le dé ou le bouton de lancer pour lancer.
  • Touchez un pion cerclé pour le déplacer.
  • Les pions cerclés sont les coups légaux de ce lancer.

Clavier

  • Espace ou Entrée — lance le dé.
  • Flèches ou Tab — parcourt les pions jouables.
  • Entrée — déplace le pion sélectionné.

Manette

  • A — lance le dé.
  • Croix directionnelle ou stick — parcourt les pions jouables.
  • A — confirme le pion sélectionné.
  • Start — ouvre ou ferme ce panneau.
