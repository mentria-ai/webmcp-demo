Qu'est-ce que Fichiers ?

Un inspecteur du stockage local pour tout ce que les outils Mentria conservent sur cet appareil. Il liste l'espace de noms de chaque application — notes, coffre TOTP, états de jeu, données d'extensions et clés héritées — avec la taille de chaque élément et sa date de modification. Consultez n'importe quelle valeur en JSON formaté, exportez un élément précis ou supprimez-le (les suppressions demandent toujours confirmation). Exportez une sauvegarde chiffrée de l'ensemble avec une phrase secrète (PBKDF2-SHA256 × 600k + AES-GCM). Rien n'est envoyé ; l'outil n'écrit dans le stockage que lorsque vous confirmez une suppression.
