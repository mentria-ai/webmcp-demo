TOTP

Codes de double authentification qui restent dans votre navigateur, chiffrés au repos. Rien sur un serveur.

Qu'est-ce que c'est ? Masquer les détails ▾

Qu'est-ce que TOTP ?

TOTP conforme au standard (RFC 6238) entièrement dans votre navigateur. Les secrets sont chiffrés au repos avec AES-GCM-256 ; une clé maître est protégée par une phrase secrète (PBKDF2-SHA256 × 600k) et optionnellement par une clé dérivée de WebAuthn PRF pour un déverrouillage Touch ID / Windows Hello. Sauvegarde chiffrée JSON obligatoire avant le premier enregistrement — perdre votre unique authentificateur signifie verrouillage sinon. Fonctionne hors ligne. Sans compte, sans serveur de sync.
