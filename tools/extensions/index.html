What is Extensions?

A bring-your-own-tool platform. An extension is one HTML file with an embedded manifest; install it here and it gets a tile in your launcher, optional terminal commands, and its own local storage that rides your encrypted backup. Extensions run with full access on this device, so only install files from people you trust. Nothing about them is ever uploaded.
