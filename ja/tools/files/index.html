~/tools/files

ファイル

Mentria のツールがこの端末に保存したデータを閲覧・エクスポート・削除できます。すべて端末内にとどまります。

これは何? 詳細を隠す ▾

ファイルとは?

Mentria のツールがこの端末に保存しているすべてのデータを確認できるローカルストレージのインスペクターです。各アプリの名前空間（メモ、TOTP 保管庫、ゲームの状態、拡張機能のデータ、旧形式のキー）を、項目ごとのサイズと更新日時とともに一覧表示します。任意の値を整形済み JSON として表示したり、個別の項目をエクスポートしたり、削除したりできます（削除時は必ず確認します）。パスフレーズ（PBKDF2-SHA256 × 600k + AES-GCM）ですべてを暗号化バックアップとしてエクスポートすることもできます。データは送信されず、削除を確認したときだけストレージに書き込みます。
