¿Qué es Flappy?

Una versión nativa del navegador de Flappy Bird con estética synthwave-terminal. HTML5 Canvas puro — sin instalación, sin registro, sin scripts de terceros. Estado del juego, récord y audio se ejecutan del lado del cliente y permanecen en tu dispositivo. Toca, haz clic o pulsa espacio para aletear. Funciona sin conexión una vez cacheado.

Controles

  • Táctil Toca o haz clic en cualquier parte del campo para aletear en uso
  • Teclado Espacio, ↑ o W para aletear · P o Esc para pausar · R para reiniciar en uso
  • Mando A para aletear · Start para pausar en uso

Cualquier entrada inicia una partida desde la pantalla de inicio o de fin
