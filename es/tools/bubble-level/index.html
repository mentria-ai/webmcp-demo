Nivel de burbuja

Convierte tu móvil en un nivel de burbuja online: un nivel de albañil sin instalar ninguna app, con precisión de 0,1° y que funciona sin conexión.

¿Qué es esto? Ocultar detalles ▾

¿Qué es Nivel de burbuja?

Apoya el móvil en una estantería y la herramienta lee la inclinación directamente del acelerómetro. Túmbalo en plano para ver una burbuja circular de dos ejes, o ponlo de canto para usar el tubo de un nivel de carpintero. Nada sale de tu dispositivo, y con un toque corriges el sesgo del propio móvil.

Se necesita acceso al movimiento

El nivel calcula la inclinación con el sensor de movimiento del móvil. Concede el acceso para empezar.

Acceso al movimiento denegado

Vuelve a activar el acceso al movimiento en los ajustes del navegador y recarga la página.

Ábrelo en tu móvil

Un nivel de burbuja necesita un sensor de inclinación y este dispositivo no lo tiene. Escanea el código con el móvil para abrir el nivel allí.
